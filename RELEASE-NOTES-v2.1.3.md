# Gang Helper v2.1.3

Aceasta este ultima versiune care trebuie instalată manual. Începând cu v2.1.4, Gang Helper verifică automat manifestul GitHub și afișează un punct roșu pe clopoțel atunci când este disponibil un update. Instalarea începe numai după apăsarea butonului `Actualizează acum`.

## Noutăți

- updater GitHub complet configurat, cu verificare SHA-256, backup și reload;
- mesaj de injectare afișat imediat după un singur `wait(0)`;
- pagina Acasă compactată, fără spațiul gol din cardul Despre mod;
- explicația update-ului mutată în dreapta pictogramei;
- contact Discord `semaka47`, cu logo vectorial redesenat numai din primitive compatibile MoonImGui legacy;
- remediat crash-ul produs la deschiderea meniului pe versiunile MoonImGui care nu expun toate primitivele moderne;
- selector de culoare compact pe două coloane;
- patru stiluri de overlay: Clean, Soft, Solid și Contrast;
- taste antialias, rotunjite uniform, fără chenare între ele;
- alb real implicit pentru tastatură și mouse;
- Bullet Track corectat pentru focurile în aer;
- marcaj auriu/alb distinct pentru impacturile în jucători.

## Instalare

1. Închide GTA San Andreas.
2. Elimină orice versiune veche `GangHelper*.lua`.
3. Copiază folderul `moonloader` din arhivă peste folderul `GTA San Andreas/moonloader`.
4. Deschide meniul cu `Del` sau `/gh`.

Configurația rămâne `moonloader/config/gang_helper.ini`.
